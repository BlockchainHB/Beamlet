Claude, within reach. Beamlet gives Claude Code Remote Control a native home in your Mac menu bar.

## In this first beta

- Start and stop Remote Control without a dedicated terminal window.
- See connection status, open Claude, copy your session link, or connect your phone by QR code.
- Choose your starting folder and Claude installation.
- Optional launch at login, automatic connection, attention notifications, and keep-awake while plugged in.
- Bounded recovery attempts and shutdown of the process Beamlet owns.

## Install

Download `Beamlet-0.1.0-universal.zip`, unzip it, drag Beamlet to Applications, and open it. This beta targets macOS 14+ on Apple Silicon and Intel. Older macOS versions and Intel runtime compatibility have not yet been verified.

You need an installed Claude Code CLI with eligible Remote Control access. Complete sign-in, workspace trust and Remote Control consent in Terminal once; stop that terminal session before starting Beamlet. [Setup guide](https://github.com/BlockchainHB/Beamlet#get-started).

## Beta notes

- Keep your Mac powered on and connected. Closing the lid can put it to sleep.
- Updates are manual through GitHub Releases; automatic updates are not enabled.
- Claude CLI changes can affect connection detection. If startup fails, first verify `claude remote-control` in the same folder in Terminal.
- Beamlet is independent of Anthropic and does not include a Claude subscription.
